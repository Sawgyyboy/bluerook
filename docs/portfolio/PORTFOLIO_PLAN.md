# Complete cinematic portfolio plan

## Thesis

Bluerook makes the hidden operation visible: signal, system, human ownership, and completed outcome. Tools remain supporting detail.

## Visitor paths

- `Story` — guided route narrative with chapter progress and purposeful motion.
- `Inspect` — interfaces, workflow nodes, records, controls, failures, and evidence are foregrounded.
- `Summary` — concise buyer-facing problem, system, human boundary, status, and next action.

## Sitemap

`/work/` is the lobby. It connects to commerce, sports enrollment, Sports Operations OS, workflow evidence, products, capabilities, system building, voice, managed operations, and the technical portfolio. The existing homepage gains only a Work destination and Selected Systems section.

## Shared implementation

- Vanilla HTML, CSS, and JavaScript only.
- Shared portfolio shell, modes, progress rail, inspectors, status disclosures, reset controls, fictional data, and accessibility behavior.
- Page-specific modules for commerce, sports, workflows, products, voice, lead systems, managed operations, and system building.
- Public content remains readable without JavaScript; interactivity progressively enhances it.

## Public trust model

Every surface uses one of the approved disclosure statuses. No client proof, production result, metric, endorsement, or live-integration status is inferred. Synthetic state is visibly labelled and resettable.
