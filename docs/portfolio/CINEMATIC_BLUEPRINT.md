# Cinematic experience blueprint

## Visual contract

The portfolio extends the established private-operations-room world: Midnight fields, Paper type, structural Bluerook Blue, and one purposeful Brass signal per composition. Interface density alternates with editorial quiet. Motion visualizes routing, approval, exception, ownership, or completion—never decoration alone.

## Signature interactions

| Chapter | Signature interaction | Completion meaning |
|---|---|---|
| Lobby | Fragmented signals resolve into an owned operations board | Every signal gains owner, next action, boundary, and completion condition |
| Commerce | Fictional backend edits synchronize storefront, dashboard, and log | One approved change reaches every connected surface |
| Product content | Suggestion moves through explicit review | AI output never publishes silently |
| Product assets | Controlled discovery populates approved synthetic assets | Rejected matches remain visible and reviewable |
| Orders | State and exception changes synchronize support, CRM, and operations | Exception receives human ownership |
| Sports enrollment | Enquiry becomes qualification, CRM, booking, and follow-up | Lead has owner and next action |
| Audit | Unsafe reply becomes recommendation, approval, update, and retest | Behavior changes only through controlled review |
| Workflow | Clickable nodes expose purpose/data/failure; deliberate break follows recovery path | Failure queues, alerts, and logs instead of disappearing |
| Gap detector | Forgotten lead returns to action after approval | Missing ownership becomes an explicit task |
| Arden | Prepared conversation updates safe state and business action | Call outcome is recorded or handed off |
| Speed to lead | Timer advances a deterministic response path | Outcome creates the correct synthetic CRM action |
| Reactivation | Dormant lead returns to pipeline with consent controls | Contact limits and opt-outs remain enforceable |
| Managed operations | Disorder composes into an executive brief | Only genuine decisions remain with the founder |
| Process to SOP | Messy transcript becomes a reviewed process | Owner and completion condition become explicit |
| System builder | Visitor choices generate an architecture and boundary summary | Operation shape becomes discussable before implementation |

## Responsive and motion rules

Desktop may use sticky narrative stages without hijacking scroll. Tablet and mobile use normal-flow step scenes and tap-to-inspect panels. Reduced-motion mode exposes the same states through static frames and direct controls. No route depends on audio, hover, horizontal scrolling, or continuous animation.
